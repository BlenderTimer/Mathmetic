Acknowledgements

This calculator is powered by bignumber.js which supports arbitrary-precision arithmetic and BigInt for the integer calculation system. Thank you @MikeMcl and all other contributors for bignumber.js!

The formula parser and some of the more complex calculations (pi, atan, etc.) are custom built. The "pi" constant is calculated using the Chudnovsky algorithm for maximum precision and accuracy (I have confirmed it to be accurate up to 1 million digits of PI).

Syntax, Functions, and Variables

Formulas are parsed using standard parsing methods. + for addition, - for subtraction, * for multiplication, / for division, % for modulo, ^ for power, ! for factorial, and !! for double factorial.

Built-in constants:

  • pi PI/π (~3.14159)

  • e Euler's number (~2.71828)

  • phi Golden ratio/φ (~1.61803)

  • tau Tau/τ (~6.28319)

Built-in variables:

  • calc1 the result from calculator 1

  • calc2 the result from calculator 2

  • calc3 the result from calculator 3

  • calc4 the result from calculator 4

  • calc5 the result from calculator 5

  • calc6 the result from calculator 6

Built-in functions:

  • sqrt(n) returns the square root of n

  • pow(n, a) returns the n to the power of a (equivalent to n^a)

  • exp(n) returns e (Euler's number) to the power of n

  • log(n) or log(n, a) returns the power of a that equals n (a is optional, defaults to 10)

  • log2(n) returns the power of 2 that equals n

  • log10(n) returns the power of 10 that equals n

  • ln(n) returns the power of e (Euler's number) that equals n

  • abs(n) returns the absolute value of n

  • mod(n, a) returns the modulo of n by a (equivalent to n%a)

  • d(n) or d(n, a) returns only the decimals of n (a is the decimal precision to use, defaults to the global decimal precision value)

  • ceil(n) returns n rounded up

  • floor(n) returns n rounded down

  • round(n) or round(n, a) returns n rounded to a decimal places (a is optional, defaults to 0)

  • min(n1, n2, ...) returns the smallest of the given numbers

  • max(n1, n2, ...) returns the largest of the given numbers

  • sum(n1, n2, ...) returns the sum of the given numbers

  • avg(n1, n2, ...) returns the average of the given numbers

  • sin(n) returns the sine of n

  • cos(n) returns the cosine of n

  • tan(n) returns the tangent of n

  • asin(n) returns the angle whose sine is n

  • acos(n) returns the angle whose cosine is n

  • atan(n) returns the angle whose tangent is n

  • sinh(n) returns the hyperbolic sine of n

  • cosh(n) returns the hyperbolic cosine of n

  • tanh(n) returns the hyperbolic tangent of n

  • rad(n) converts n degrees to radians

  • deg(n) converts n radians to degrees

  • repeat(n, a, b) repeats the calculation of n a times and returns the final number (the repeat function also provides a variable "n" which is the number of repetitions at the point of calculation and a variable "v" which is the previously calculated number with parameter b as the starting value)

  • repeatSum(n, a) repeats the calculation of n a times and returns the sum (the repeatSum function also provides a variable "n" which is the number of repetitions at the point of calculation)

  • dist(x1, y1, x2, y2) returns the 2D distance between points 1 and 2

  • dist3(x1, y1, z1, x2, y2, z2) returns the 3D distance between points 1 and 2

  • sphere(n) or sphere(n, t) returns the volume of a sphere with: the given radius if t is 0 (default), the given diameter if t is 1, the given circumference if t is 2

  • sound(c) or sound(c, p, h) takes c (temperature in Celsius) and returns the speed of sound in air in m/s. If p (pressure in kPh) and h (relative humidity, 0-100) are provided the function will use the more precise NIST standard of the Cramer and Arden Buck equations.

  • fibonacci(n) returns the Fibonacci number from n.

  • prime(n) returns the nth prime from n.

Unit conversions:

The parser supports conversion between many units of measurement including units such as kilometers, miles, joules, kilowatt-hours, etc. The syntax is very straight forward. Here are some examples:

  • 5km to mi converts 5 kilometers to miles

  • 5 kilometers to miles converts 5 kilometers to miles

  • 5s to ms converts 5 seconds to milliseconds

  • (123/5) bar to psi converts 24.6 bar to PSI
